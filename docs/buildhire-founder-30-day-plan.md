# BuildHire Founder Action Plan — Next 30 Days

This plan focuses the founder’s time on the actions that convert the completed website work into accountable leads, confirmed hires, revenue and local-search authority. It assumes the newly implemented website events and quote workflow are active.

## The two actions to complete first

> **Action 1:** In GA4, mark `generate_lead`, `whatsapp_booking_start` and `equipment_planner_quote_start` as key events. This turns the new website measurement into a usable lead dashboard. [1]

> **Action 2:** Use the BuildHire Google Maps profile in every post-hire review request. It is a genuine local trust asset, not a source of fabricated testimonials. [2]

| Priority | Founder action | Time | Outcome to record |
|---|---|---:|---|
| 1 | Mark the three GA4 events as key events. | 15 min | Key events visible in GA4. |
| 2 | Start using a quote ID in each WhatsApp enquiry, quote and confirmed hire. | 30 min | Every confirmed hire can be tied to a source landing page. |
| 3 | Add or verify local business profiles. | 60–90 min | Consistent profile data and approved profile links. |
| 4 | Send review requests after completed hires. | 10 min per week | Honest reviews and review-request completion rate. |
| 5 | Send five relevant partner enquiries per month. | 60 min per week | Replies, meetings and relevant referral / listing opportunities. |

## Week 1 — Measurement and local entity

### 1. Configure GA4 conversion measurement

1. Open [Google Analytics](https://analytics.google.com/).
2. Select the BuildHire property, then go to **Admin → Events**.
3. When they appear, mark these as **key events**: `generate_lead`, `whatsapp_booking_start`, and `equipment_planner_quote_start`.
4. Create one exploration or report with **Landing page**, **Session source/medium**, **Event name**, and **Equipment category**.
5. Review it weekly. Do not send customer names, phone numbers, dates or free-text WhatsApp messages to GA4.

### 2. Apply the quote-ID rule

Use one short ID on every qualified WhatsApp enquiry, such as `BH-20260812-014`. Add it to the WhatsApp conversation, quote record and confirmed booking.

| Capture point | Required fields |
|---|---|
| First qualified enquiry | Quote ID, source/medium, landing page, machine category, suburb. |
| Quote issued | Quote ID, proposed machine, dates, delivery quote, total quote value. |
| Hire confirmed | Quote ID, actual hire revenue, delivery revenue, estimated gross profit. |
| Hire completed | Quote ID, review request sent, review completed, issue/resolution flag. |

This is the minimum viable system for determining whether SEO pages produce revenue rather than merely traffic.

### 3. Verify business profiles

Keep the business name, address/service area, phone number, website and category consistent. Use only the real operating address or service area.

| Directory | Founder task | Link |

| Google Business Profile | Verify the profile, complete categories/service areas, add current equipment photos and respond to genuine reviews. | https://business.google.com/ |
| Bing Places | Import from Google Business Profile or create a consistent verified listing. | https://www.bingplaces.com/ |
| Apple Business Connect | Claim/verify BuildHire and connect the current website. | https://businessconnect.apple.com/ |

## Week 2 — Genuine review system

The website now has a **Read our Google reviews** link prepared for the verified profile. The review profile currently shows authentic public Google reviews; the site should link to the profile but must not add static rating markup or copied review text.

### When to ask

Send the request **one day after equipment collection**, provided the hire is complete. Send one follow-up after seven days only if there is no review. Ask every eligible customer, not only customers expected to leave positive feedback.

### Copy/paste WhatsApp message

> Hi {{first_name}}, thanks for hiring with BuildHire for {{job_or_suburb}}. If you have a minute, we would value an honest review of your experience: https://www.google.com/maps/place/Build+Hire/@-33.9408948,151.1462229,17z/data=!3m1!4b1!4m6!3m5!1s0x6b12b1f5096e47dd:0x7f336a7703f34d66!8m2!3d-33.9408948!4d151.1462229!16s%2Fg%2F11z3_y1zcp. Your feedback helps local trades choose equipment hire with confidence. Thank you — BuildHire.

Never offer a discount, incentive or reward for a review. Never ask for a particular rating. Never selectively invite only happy customers.
